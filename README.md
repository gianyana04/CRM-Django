# CRM con Django

Este es un proyecto personal utilizando Djando y como base de datos se utilizo MySQL

## 1. Crear el entorno vitual

```shell 
py -m venv .venv
```

```shell
.venv\Scripts\Activate.ps1
```
## 2. Descargar Django

```shell
pip install django 
```

- Si se presenta problemas de campatibilidad se puede bajar de version de Django para evitar errores.

```shell
pip install "django<6.0"
```
## 3. Descargar los conectores de base de datos

```shell
pip install mysql
```

```shell
pip install mysql-connector-python
```

## 4. Implementacion visual

Se utilizo **[bootstrap*](https://getbootstrap.com/docs/5.3/getting-started/introduction/)** se utilizo la version 5.3 para el proyecto.
